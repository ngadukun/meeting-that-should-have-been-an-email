A one-line joke about a meeting that should have been an email, written for the
[make.fun bounty](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

`main.ts` (Node 22) writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). One line, plain text, at most 200 characters:

> Nine people, one hour, and a 40-slide deck later, we reached the exact conclusion the email's subject line had already reached.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/meeting-out node main.ts
cat /tmp/meeting-out/entry.txt
```
